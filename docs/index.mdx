## Install with Claude

This documentation site is also bundled as an Agent Skill, which Claude Code can use to walk you through the installation process. Before carrying out the steps below, you might prefer to [install the prerequisites manually](/docs/prerequisites). If not, Claude will walk you through that too.

<Steps>
<Step>
[Install Claude Code](https://code.claude.com/docs/) and log in

```bash
claude auth login
```
</Step>
<Step>
Clone [boltmcp](https://github.com/boltmcp/boltmcp)

```bash
git clone https://github.com/boltmcp/boltmcp.git
```
</Step>
<Step>
Move your BoltMCP access key to the `keys` directory

```bash
mv ~/Downloads/my-key.json boltmcp/keys/boltmcp-key.json
```
<Callout type="info">
  Replace `~/Downloads/my-key.json` with the path to your access key file
</Callout>
</Step>
<Step>
Open Claude Code from inside the `boltmcp` directory

```bash
cd boltmcp && claude
```
</Step>
<Step>
Invoke the Skill and Claude will walk you through the installation process

```
/install-boltmcp Install BoltMCP on a new cluster
```

<Callout type="info">
  Replace the text after "/install-boltmcp " with any instruction related to installing, updating or uninstalling BoltMCP.
</Callout>
</Step>
</Steps>
